## 2. Scope control

Only the Transcript Request vertical slice is fully functional in Stage 1. Clearance Request and Certificate Replacement remain simplified demonstrations. Transfers, broad builders, public verification, advanced reporting, predictive analytics and other Stage 0 exclusions cannot enter through roadmap sequencing.

## 3. Change rule

Any feature/scope priority change belongs first in the authoritative Stage 0 decision/non-goal/backlog documents. This roadmap may then mirror the approved sequencing change.
