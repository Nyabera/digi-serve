# D29R-23A — External sharing and dashboard greeting

The Share Workflow / Refer Case experience now supports two destinations:

- an internal college department and officer;
- an external email address or phone number.

The external option creates a read-only, seven-day demo link and records a
local success state. No message is actually sent and no network access is
introduced.

The wave emoji is removed from Demo dashboard greetings while preserving the
existing greeting copy and layout.
