# Demo Presentation Script

## Preparation

1. Run the full verification gate.
2. Start the application.
3. Open `/demo`.
4. Reset the Demo.
5. Confirm request `STC-CL-2026-0027`.
6. Keep the workflow builder open in another tab.

## Applicant

1. Show the homepage and service catalogue.
2. Open one service.
3. Start a request.
4. Show required information and simulated documents.
5. Open tracking and explain progress visibility.

## Officer

1. Select Officer.
2. Show the dashboard and queue.
3. Open a case.
4. Show submitted data, comments and history.
5. Demonstrate internal referral.
6. Demonstrate email or phone sharing.
7. Show personal SLA.

## Supervisor

1. Select Supervisor.
2. Show approvals, audit trail and workload.
3. Show department SLA.
4. Show reports and takeaways.

## Admin

1. Select Admin.
2. Open Workflows.
3. Show templates and active workflows.
4. Open the visual builder.
5. Drag, drop and reorder a step.
6. Edit assignee, SLA, conditions and timeout handling.

## Architecture statement

“One Demo Engine loads different Demo Packs. A supermarket or hospital pack
changes branding, services, departments, workflows and data. The underlying
Officer, Supervisor, Admin, SLA and audit mechanics stay the same.”
