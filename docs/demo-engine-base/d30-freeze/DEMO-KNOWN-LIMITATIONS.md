# Demo Known Limitations

## Engine limitations

- state is primarily browser-seeded;
- production authentication is not demonstrated;
- uploads and payments are simulated;
- email and SMS actions are simulated;
- workflow publishing is demonstrative;
- reports and SLA values use seeded data;
- production integrations are outside D30.

## TVET pack limitations

- Savannah Technical College is fictional;
- people and contact details are fictional;
- service demand and SLA performance are illustrative;
- request histories and documents are seeded;
- workflow usage counts are illustrative.

Present the system as a working product demonstration, not as evidence that
every production integration is already deployed.
