# D29R-22 — Six student-service cards

The Savannah Technical College homepage now contains six popular services:

1. Request an academic transcript
2. Complete student clearance
3. Replace a lost certificate
4. Get an industrial attachment letter
5. Apply for a new course
6. Register for classes

## New card copy

**05 — Apply for a new course**

Choose a course, submit your qualifications and track your application through
review and admission.

**06 — Register for classes**

Select your units for the upcoming term and submit them for academic and
finance clearance.

The cards use the existing dynamic service-information route. This stage does
not add new static page routes or redesign the homepage.
