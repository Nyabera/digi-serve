# D29R-23C — Functional workflows for five services

This stage adds functional, seeded public journeys for:

1. Student clearance
2. Certificate replacement
3. Industrial attachment letters
4. New-course applications
5. Class registration

Transcript Request is not replaced or modified.

Each service includes:

- a service-information page;
- a guided application;
- simulated document uploads;
- service-specific fields and stages;
- a fixed demo case ID;
- an applicant tracker with a progress chart;
- a browser-only stage-advance control;
- payment/reference status;
- assigned officer and coordinating department;
- final-output possibilities.

No API call, Supabase write, payment transaction or file upload is made.
