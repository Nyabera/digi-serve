## Intended files

- `manifest.ts` — pack entry point;
- `organization.ts` — organization identity and contact information;
- `branding.ts` — logo, colours and supported visual tokens;
- `homepage.ts` — homepage content and presentation settings;
- `departments.ts` — departments and routing targets;
- `users.ts` — fictional Demo users and staff;
- `services.ts` — service definitions;
- `workflows.ts` — workflow templates and approval chains;
- `requests.ts` — seeded request data;
- `reports.ts` — report metrics and chart datasets;
- `sla.ts` ment SLA targets;
- `assets/` — pack-owned visual assets.
