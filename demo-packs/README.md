# FAIDIA Demo Packs

FAIDIA uses one reusable Demo Engine and multiple organization-specific Demo Packs.

A Demo Pack supplies:

- organization identity;
- branding;
- homepage content;
- departments;
- users;
- services;
- workflow definitions;
- seeded requests;
- reports;
- SLA data;
- presentation assets.

A Demo Pack must not contain copied role shells, copied application routes or duplicated workflow execution logic.
